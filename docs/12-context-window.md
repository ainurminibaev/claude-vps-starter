# Контекст локального профиля Codex

Для явных имён `gpt-6-astra` и `gpt-6.1-sol` Claude Code 2.1.316
использовал окно неизвестной модели 200k: реальные автоматические сжатия
происходили около 167–170k. Переменная AUTO_COMPACT_WINDOW=475000 сама
по себе не увеличивала распознанное окно.

Локальный профиль теперь устанавливает:

```text
CLAUDE_CODE_MAX_CONTEXT_TOKENS=1050000
CLAUDE_CODE_AUTO_COMPACT_WINDOW=900000
```

Нативная проверка `claude -p /context --model gpt-6-astra` показала окно
900k и Autocompact buffer 33k: ожидаемый порог около 867k. Проверка
не выполняла API-запросов. Запрос на 900k к upstream отдельно не проверялся.
Переменная MAX_CONTEXT применяется к неизвестным CLI именам без суффикса
`[1m]`; это не универсальная настройка для любых моделей. При выборе модели
с меньшим реальным окном настройки необходимо пересмотреть.

Изменение установлено локально. Открытые процессы нужно завершить и
возобновить через `claude -r`; история сохраняется. Настройки VPS этим
изменением не обновлялись. Переключение на профиль Claude восстанавливает
сохранённые значения переменных или удаляет добавленные профилем.
